# @ywzhang1031/dsh-client-ui-aside

[English](README.md) | 中文

只读旁注的浏览器界面。在已完成的助手回复中选中一段文字，点击浮动的**就此提问**按钮（或消息动作条上的 💬 按钮），一个空白的草稿抽屉就会绑定到该选区打开——此时还没有任何持久化内容。输入问题并发送后，fork 出的旁注才会真正创建，锚定原文随之附在首问上。关闭未发送的草稿不留任何痕迹。

**无需任何源码修改即可运行在 stock DSH 部署上**：插件通过 `ctx.remote.$mount` 自行挂载生成的 Remote stub，从运行时 sessions 服务读取当前会话（stock 渲染器不发布任何 DOM 身份属性），并把消息级入口贡献给 stock 的 `conversation.chat.assistant-actions` 动作条——与 `ui-message-feedback` 用的是同一个扩展点。

插件拥有六块内容，均为客户端表现层状态：

- **`AnchorStore`** — 「被问片段 → 旁注」的映射，持久化于 `localStorage`；按 (session, message?, text) 幂等。
- **`DrawerStore`** — 抽屉打开状态机：草稿（绑定选区、尚无会话）只在首次发送成功后才挂到真实旁注上。
- **`SelectionWatcher`** — 文档级监听器，把选区解析到**当前会话**（经运行时 sessions 服务），并浮出提问按钮。
- **`AsideDrawer`** — overlay 槽面板：通过 connection API 轻量轮询读取历史，通过 `sessions.prompt` 发送，并用共享 markdown 渲染器渲染助手正文。
- **`AsideSidebar`** — Codex 风格常驻侧栏：产出文件、网页搜索来源、当前对话的旁注聊天列表（从会话历史折叠而来）；旁注条目在抽屉中重开对应会话。
- **`AsideAskAction`** — stock 助手消息动作条上的消息级入口：携带该消息的精确 `messageId`（DOM 监听器看不到它），从历史解析消息文本后打开同一个草稿抽屉。

持久权威——旁注会话、fork 血缘、只读姿态——都在 Host（`@ywzhang1031/dsh-aside-host`）一侧；清空浏览器存储只会隐藏锚点列表，永远不会删除旁注本身。

## stock-only 取舍

- **没有原文内联高亮。** stock `MarkdownText` 没有装饰钩子，被问文字无法在主对话原文中高亮。重入改为走消息 💬 按钮、侧栏「旁注聊天」列表与会话列表。
- **选区归属为会话级。** 浮动按钮只把选区归到当前会话（无 `messageId`）；消息级按钮提供精确到消息的锚定。

## Model Experience

无——本浏览器端界面不注册任何模型工具、提示词段落或 provider 路由；旁注的每个模型请求都由自组装的只读世界负责。

#### KV Cache 影响

无；本包从不组装模型输入。

## 已知限制与待办

- **锚点是浏览器本地的** — `localStorage` 账本是表现层状态；清空存储会隐藏旁注列表，但旁注会话仍可从会话列表访问。
- **轮询历史** — 抽屉与侧栏在打开期间靠轻轮询刷新，而非订阅实时 mux 流；流式保真度留待后续。
- **选区作用于对话表面** — 浮动按钮出现在对话表面的选区上；消息级入口（💬 按钮）是精确到消息的入口。
- **侧栏产物路径是原始的** — 终端命令间接产出的文件没有变更位置，不进入产物折叠，与 deliverables 词汇保持一致。
